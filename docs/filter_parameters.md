# フィルタパラメータの既定値と根拠

清明モードとの差が明確に出るよう、清明以外のモードは強めの劣化を与える値にしている。

## 実測した正答率（モデル: clef / 生成モード別）

| 視力 | 清明 | 近視 | 混濁 | 乱視 |
|------|------|------|------|------|
| 1.0（小さい環） | 100% (8/8) | 25% (2/8) | 25% (2/8) | 25% (2/8) |
| 0.5 | — | 100% (4/4) | 25% (1/4) | 75% (3/4) |
| 0.1（最大の環） | — | 100% (4/4) | 100% (4/4) | 100% (4/4) |

- 視力1.0では清明だけが読め、清明以外はチャンスレベル（25%）まで落ちる。
- 視力0.1（環が最大）ではすべてのモードが読めるため、検査自体は成立する。
- 劣化の強さは 混濁 > 乱視 > 近視 の順で、読めなくなる視力値がモードごとに異なる。

## 近視（GaussianBlur）

| パラメータ | デフォルト | 値域 | 説明 |
|------------|-----------|------|------|
| カーネルサイズ | 61 | 3, 5, ..., 119, 121 | ぼかしの強度。大きいほど強くぼける |
| シグマ | 0 | 0 固定 | 0 にすると OpenCV がカーネルサイズから自動算出する（カーネル61で約9.5） |

## 混濁（boxFilter + コントラスト低下）

| パラメータ | デフォルト | 値域 | 説明 |
|------------|-----------|------|------|
| boxFilter カーネルサイズ | 41 | 3, 5, ..., 79, 81 | 平滑化の範囲。大きいほど強くぼける |
| コントラスト係数 | 0.15 | 0.05 〜 1.0 | 1.0 で変更なし、小さいほどコントラストが下がる（白濁感） |

## 乱視（filter2D カスタムカーネル）

| パラメータ | デフォルト | 値域 | 説明 |
|------------|-----------|------|------|
| カーネルサイズ | 61 | 15, 17, ..., 109, 111 | ぼかしの広がり。大きいほど広くぼける（上限は下記「キャンバスサイズ」参照） |
| 方向（角度） | 0° | 0° 〜 180° | 0° = 水平方向にぼかす |
| 強度（長方形比率） | 0.95 | 0.50 〜 0.98 | 1.0 に近いほど一方向に強くぼける |

## キャンバスサイズ（640×640）

最も大きい環（視力 0.1 で外径 527px）に、各フィルタのぼけの広がりを足したときの
「中心からのインク半径」を実測した結果は次のとおり。640px なら半辺 320px なので、
**既定パラメータでは最小でも約 31px の余白**があり、環がキャンバスからはみ出さない。

| 生成モード | インク半径（px） | 640 での余白（px） |
|------------|-----------------|-------------------|
| 清明 | 264 | 56 |
| 近視（既定 61） | 283 | 37 |
| 近視（最大 121） | 302 | 18 |
| 混濁（既定 41） | 279 | 41 |
| 混濁（最大 81） | 275 | 45 |
| 乱視（既定 61） | 288 | 32 |
| 乱視（上限 111） | 約 316 | 約 4 |

乱視のカーネルサイズ上限は、ぼけの広がりがキャンバスに収まる値（111）に定めている
（151 では視力 0.1 のときに最大で約 8px はみ出すため）。

## 既定値の一元管理

既定値は `src/systemone_vision_test/config.py` の定数（`*_DEFAULT` / `*_RANGE`）を基に、
`src/systemone_vision_test/domain/landolt.py` の `PARAMETER_SPECS` が単一の定義としてまとめている。
`LandoltCParams` のフィールド既定値・GUI のスライダー初期値と値域・「デフォルトに戻す」ボタンの値・
統計バッチ（`systemone_vision_test.benchmark`）と GUI はすべてそこを参照している。
